# AI Contract Assistant

## Description
This project aims to build an AI contract assistant that ingests contracts, extracts relevant information and allows users to query it. 

## Learning objectives
This is a learning project, aimed at improving my knowledge of LLMs, RAGs. It should use:
- Python for general programming
- DuckDB for SQL querying, data storage
- Mistral AI API (will be expanded later)
- Streamlit for the front end

Later on it will need to deployed on the Cloud
